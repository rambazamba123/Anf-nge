# Lektorat: Befunde und Entscheidungen

> HR61 (`docs/reise.md`): Jede fertige Folge und jede neue oder geänderte Animation geht an einen unabhängigen Lektor. Paket: `node tools/lektorat.js <folge> --bilder`, Auftrag: `podcast/lektorat-auftrag.md`. Hier steht je Folge, was der Lektor gefunden hat und was daraus wurde (behoben, abgelehnt mit Grund). So sieht man, welche Fehlerarten sich wiederholen (die kommen in `docs/fehler-katalog.md`).
